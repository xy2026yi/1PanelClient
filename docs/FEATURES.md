# 1PanelClient 功能列表

> 基于 v0.2.x（2026-10）梳理；当前功能的勾选状态与实测记录见
> [TEST-CHECKLIST.md](TEST-CHECKLIST.md)。
>
> 本文档为已有功能的完整清单与简要说明；安装、构建、API 认证等使用说明见 [README-CN.md](README-CN.md) / [README-EN.md](README-EN.md)。

## 1. 应用框架

| 功能 | 说明 |
|------|------|
| 三 Tab 布局 | 首页 / 管理 / 设置；三 Tab 保活切换（ZStack opacity），进入管理子页面时自动隐藏底部 Tab 栏 |
| iPad 自适应 | ≥800pt 自绘侧栏 / 600–800pt 图标栏（可折叠、记忆状态）/ <600pt 底部 Tab 栏；⌘1/2/3 键盘快捷键切 Tab |
| 首次启动引导 | 无服务器时显示欢迎页，引导添加第一台服务器；切服 / 移服自动收拢导航栈 |
| 中英双语 | 内置 L10n 文案表（3500+ 词条），设置中切换语言即时生效 |
| 外观主题 | 跟随系统 / 亮色 / 暗色 |
| 触觉反馈 | Tab 切换、长按菜单、关键操作带系统触觉反馈 |
| 应用锁 | FaceID / TouchID 生物识别 + 4 位数字密码回退；连续输错递增锁定时长；退后台或锁屏即重新上锁 |
| 表单组件体系 | 描边样式（Outlined）表单组件：输入框 / 密码框 / 数值+单位 / 下拉 / 多行（形态 1–10 分族），全站表单统一 |
| 列表交互统一 | 单击进入 + 长按半屏操作菜单（启停 / 编辑 / 删除 / 源文等）；VoiceOver 经「更多操作」自定义动作可达 |

## 2. 首页（概览）

| 功能 | 说明 |
|------|------|
| 资源概览 | 负载 / CPU / 内存 / 各磁盘挂载点实时卡片（3 秒轮询），点击进入监控图表 |
| 统计卡 | 网站 / 应用（含可升级数）/ 数据库 / 容器计数，点击直达对应模块 |
| 系统与面板信息 | 主机名、发行版、内核、启动与运行时间；面板版本 / IP / 时区 / 监控状态 |
| 面板更新 | 版本升级横幅 + 更新日志页 |
| 多机总览卡片 | 多节点关键指标一览（单节点也显示） |
| 服务器管理入口 | 顶栏进入服务器列表页 |

## 3. 服务器与多机管理

| 功能 | 说明 |
|------|------|
| 多服务器管理 | 服务器添加 / 编辑 / 删除，凭据存于 Keychain；分组管理（网站 / 计划任务 / 脚本分组共用） |
| 连接测试 | 保存前验证面板地址与 API Key 可用性 |
| 服务器列表 | 在线 / 离线徽标、逐磁盘 32pt 指标环，5 秒轮询刷新；一台服务器一张卡片 |
| 长按服务器操作 | 半屏面板：编辑 / 重启面板 / 重启服务器 / 删除；重启按目标服务器凭据直发，需输入「立即重启」确认 |
| 多机管理（专业版） | 节点概览 / 详情（同步与更新记录、重启）/ 添加三页向导 / 编辑 / 删除 / 一键切换，App 全局接口与界面跟随当前节点 |

## 4. 管理模块

「管理」页入口按 应用 / 主机 / 工具箱 / 高级功能 / 面板 分组展示（见 `Features/Manage/ManageTab.swift`）；支持「自定义功能」编辑页显隐与排序，高级功能按许可证门禁。

## 5. 安全

| 功能 | 说明 |
|------|------|
| Keychain 存储 | API Key 等凭据仅存于 iOS Keychain，不落明文文件 |
| 仅 HTTPS 连接 | 开关开启后拒绝所有 `http://` 明文面板地址；保存 HTTP 地址时给出明文风险提示 |
| 应用锁 | 见「应用框架」；锁定期清理内存中的敏感凭据 |
| 请求安全 | 服务端请求仅 http/https；请求前校验 host，拒绝 localhost / 环回 / 私有与保留地址 |
