## 总则

1PanelClient 是开源服务器管理面板 [1Panel](https://1panel.cn) 的 iOS 客户端。
本应用**不收集、不上传任何用户数据**——无内嵌分析 SDK、无广告、无追踪、无账号体系。

## 数据存储与使用范围

| 数据 | 存放位置 | 用途 | 是否离开设备 |
|---|---|---|---|
| 面板地址、名称、API 密钥 | iOS 系统钥匙串（Keychain） | 连接你自己的 1Panel 面板 | 否（仅发往你配置的面板地址） |
| 应用偏好（主题、语言、应用锁开关等） | 本机 UserDefaults | 记住你的设置 | 否 |
| 应用锁密码 | 系统 Keychain / 本地 | 本机解锁校验 | 否 |
| 面板数据的本地缓存 | 本机 App 沙盒 | 离线展示最近一次快照 | 否 |
| 诊断数据（MetricKit） | 本机 `Application Support` | 崩溃/性能自诊断，保留 30 天 | 否（仅当你主动在「诊断数据（本地）」页分享导出） |

## 网络请求

所有请求仅发往**你本人添加**的面板地址；应用不连接任何开发者或第三方服务器。
若你配置了 `http://` 明文地址，界面会明示风险，并可在设置中开启「仅允许 HTTPS 连接」。

## 权限使用

- **本地网络**：用于连接局域网内的面板，仅在你主动测试连接时触发系统弹窗。
- **面容 ID / 触控 ID**：仅用于应用锁解锁（可选功能），不上传任何生物信息。

## 删除数据

卸载应用即删除本机所有数据（Keychain 条目随卸载清除）；面板侧的 API 密钥可随时在
1Panel 面板「面板设置 → API 接口」中禁用或重新生成。
