# 1PanelClient 功能列表

> 适用版本：v0.1.9（2026-08）· 依据源码 `Features/`、`PanelShared/`、`PanelWidgets/` 梳理
>
> 本文档为已有功能的完整清单与简要说明；安装、构建、API 认证等使用说明见 [README-CN.md](README-CN.md) / [README-EN.md](README-EN.md)。

## 1. 应用框架

| 功能 | 说明 |
|------|------|
| 三 Tab 布局 | 首页 / 管理 / 设置；进入管理子页面时自动隐藏底部 Tab 栏 |
| 首次启动引导 | 无服务器时显示欢迎页，引导添加第一台服务器 |
| 中英双语 | 内置 L10n 文案表，设置中切换语言即时生效 |
| 外观主题 | 跟随系统 / 亮色 / 暗色 |
| 触觉反馈 | Tab 切换、关键操作带系统触觉反馈 |
| 应用锁 | FaceID / TouchID 生物识别 + 4 位数字密码回退；连续输错递增锁定时长；退后台或锁屏即重新上锁 |

## 2. 首页（概览）

| 功能 | 说明 |
|------|------|
| 资源概览 | CPU / 内存 / 磁盘 / 网络 / 负载指标卡片 |
| 实时监控图表 | 自绘监控图表（与监控模块同构，统一 Y 轴与时间轴） |
| 系统信息 | 主机名、系统版本、内核版本、运行时间 |
| 面板更新检测 | 检测 1Panel 面板新版本 |
| 证书到期倒计时 | 汇总网站 SSL 证书剩余有效期提醒 |
| 多机总览卡片 | 多节点关键指标一览（单节点也显示） |
| 应用 / 容器卡片 | 应用可更新数、容器运行状态；切回首页自动轻量刷新 |
| 服务器管理入口 | 顶栏进入服务器列表页 |

## 3. 服务器与多机管理

| 功能 | 说明 |
|------|------|
| 多服务器管理 | 服务器添加 / 编辑 / 删除，凭据存于 Keychain |
| 连接测试 | 保存前验证面板地址与 API Key 可用性 |
| 服务器列表 | 状态、地址、运行时长、逐磁盘 32pt 指标环，5 秒轮询刷新；一台服务器一张卡片 |
| 长按服务器操作 | 半屏面板：编辑 / 重启面板 / 重启服务器 / 删除；重启按目标服务器凭据直发，非当前服务器同样可执行，需输入「立即重启」确认 |
| 多机管理（专业版） | 节点概览 / 节点详情 / 添加 / 编辑 / 删除 / 一键切换，App 全局接口与界面跟随当前节点 |

## 4. 管理模块（20 个入口）

| 模块 | 说明 |
|------|------|
| 应用程序 | 已安装应用列表与详情；应用商店安装 / 卸载 / 升级；升级前 Compose 参数差异高亮对比、按块采用旧配置，新配置支持全屏查看 / 编辑与内嵌显示来回切换；应用日志；安装 / 升级任务进度 |
| 网站 | 网站列表 / 创建 / 详情 / 基础配置；反向代理；域名与目录管理；网站日志（运行 / 访问） |
| SSL 证书 | 证书列表与详情；申请（DNS / HTTP 方式）、手动上传、自签发；CA 管理；DNS 账号管理 |
| 网站监控 | 概览图表（流量 / PV / UV / 访客趋势）、监控记录与详情、访客地图 |
| 数据库 | MySQL / PostgreSQL / Redis 实例管理；创建数据库；连接信息；远程访问设置 |
| 容器 | 容器列表 / 创建 / 编辑 / 详情；容器启停、删除、日志、终端；镜像列表 / 拉取 / 清理 / 仓库管理 |
| 容器监控 | 单容器 CPU / 内存 / 网络 I/O 实时图表（1 秒轮询，CPU 利用率封顶） |
| 计划任务 | 定时任务 CRUD（Shell 脚本 / 备份等类型）；立即执行；执行记录与日志；脚本库（含风险标注） |
| 终端 | WebSocket 远程终端：面板主机 / 容器 / 数据库；SSH 主机管理；键盘辅助条（方向 / Tab / Ctrl 组合键） |
| 文件 | 服务器文件管理：目录浏览、上传下载、重命名 / 删除 / 权限等操作 |
| 监控 | 负载 / CPU / 内存 / 磁盘 I/O / 网络的历史监控图表，多时间跨度切换 |
| 进程 | 系统进程列表（CPU / 内存排序）、进程详情 |
| SSH 服务管理 | 面板主机 SSH 服务开关与配置管理 |
| 防火墙 | 端口规则与 IP 规则的列表 / 创建 / 删除 / 启停 |
| Fail2ban | SSH 防暴力破解服务管理（运行状态、配置、封禁列表） |
| WAF | 网站防护全局配置；IP 规则、黑白名单（IP / URL / UA）、常见规则、IP 组、爬虫池；WAF 监控（拦截图表与记录） |
| 告警通知 | 告警规则管理、告警日志、发送方式（邮件等）与全局配置 |
| 备份账号 | MINIO / WebDAV / SFTP 备份账号管理；备份列表与快照文件管理 |
| 任务中心 | 应用同步、镜像拉取等异步任务列表与日志详情 |
| 日志 | 面板系统日志、操作日志、SSH 登录日志、网站日志的查询与查看 |

> 「管理」页入口按 应用 / 主机 / 安全 / 面板 / 高级功能 分组展示（见 `Features/Manage/ManageTab.swift`）；重启面板 / 重启服务器已移至 服务器页长按操作。

## 5. 安全

| 功能 | 说明 |
|------|------|
| Keychain 存储 | API Key 等凭据仅存于 iOS Keychain，不落明文文件 |
| 仅 HTTPS 连接 | 开关开启后拒绝所有 `http://` 明文面板地址；保存 HTTP 地址时给出明文风险提示 |
| 应用锁 | 见「应用框架」；锁定期清理内存中的敏感凭据 |

## 6. 桌面小组件与 App Intents

| 功能 | 说明 |
|------|------|
| 服务器状态小组件 | 桌面 / 锁屏查看当前服务器 CPU、内存等状态概览 |
| 容器快捷操作小组件 | 交互式按钮，直接启停指定容器（App Intents） |
| 快捷指令 | 通过 App Intents 暴露面板操作，可在快捷指令中调用 |
| 共享凭据 | App Group + 共享 Keychain，小组件与主 App 共用登录态（未签名分发时自动回退） |

## 7. 测试（Swift Testing）

覆盖：Token 签名算法（MD5 固定向量）、API 业务信封解析、Keychain 增删改查、连接安全策略（明文识别 / 仅 HTTPS 拦截）、Compose 升级差异、监控图表窗口、节点与多机模型、网站监控模型、WAF 监控模型、App Intents、本地化文案（`1PanelClientTests/`，共 11 个测试文件）。

## 8. 构建与分发

- `build-ipa.sh`：无需证书的未签名 IPA 打包脚本（适用于 LiveContainer / 侧载）。
- `scripts/`：i18n 文案迁移与同步辅助脚本。
- 版本号三 target 同步（App / Tests / Widgets）。
