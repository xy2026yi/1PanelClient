# 1PanelClient 全功能测试清单

> 版本：v0.1.20+（2026-09）· 面板适配 v2.3.0 – v2.3.1（v2.3.x 原则兼容）
>
> **⚠️ 当前状态（重要假设）：全部功能仅完成了开发，尚未做过任何真机 / 模拟器的功能验证。**
> 本清单即首次全量验收清单：测一项勾一项（`[ ]` → `[x]`）；发现问题直接在该项下方的「结果」行写情况（现象 / 复现步骤 / 面板版本），修复后复查再勾选。
>
> 单元测试（323 项，Swift Testing）已全绿且接入 CI；本清单覆盖的是**单元测试无法覆盖的 UI 与真实面板交互**。
>
> 建议环境：真机 + 面板 v2.3.1（另备一台 v2.3.0 验证跨小版本兼容）、社区版 + 专业版各一（许可证功能）、至少一个远程备份账号（MINIO/WebDAV/SFTP 任一）。

## 使用方法

- 每项测完将 `- [ ]` 改为 `- [x]`
- 有问题时在对应项下写：`- 结果：现象 + 复现步骤 + 面板版本`
- 优先级标注：🔴 核心（先测）/ 🟡 常用 / ⚪ 低频
